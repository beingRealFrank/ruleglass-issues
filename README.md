# Ruleglass

Free JetBrains IDE plugin for PromQL and Prometheus rule files. Works offline: no network calls, no data collection.

[![Downloads](https://img.shields.io/jetbrains/plugin/d/36121)](https://plugins.jetbrains.com/plugin/36121-ruleglass)

## Install

In your IDE: **Settings | Plugins | Marketplace**, search for **Ruleglass**, then **Install**. Or get it from [JetBrains Marketplace](https://plugins.jetbrains.com/plugin/36121-ruleglass).

## Features

- PromQL highlighting, also inside the `expr:` fields of Prometheus rule YAML
- Completion and quick documentation for functions and keywords
- Inspections for unknown functions and range-vector mistakes
